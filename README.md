# Toll PH

Toll calculator for Philippine expressways (NLEX, Skyway, SLEX, MCX, NAIAX,
CAVITEX, CALAX): pick where you enter and exit and see each toll, the route
step by step, and fuel + toll totals. Class 1-3.

Fees charged at the toll plaza prevail. Rates are checked against published
TRB / operator figures; see the footer in the app for each road's date.
